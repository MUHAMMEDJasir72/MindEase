# MindEase

MindEase is an online mental health platform that connects users with licensed psychologists through secure **video**, **voice**, and **chat** sessions. The platform offers a simple and user-friendly experience to schedule therapy sessions, ensuring accessibility, privacy, and comfort for those seeking mental health support.

## 🌐 Live Project

Visit: [https://mindeasee.shop](https://mindeasee.shop)

---

## ✨ Features

- ✅ User registration & login (with email verification)
- 🧠 Book therapy sessions by video, voice, or chat
- 📆 Schedule appointments with available psychologists
- 💬 In-app chat functionality with psychologists
- 📺 1:1 private video call integration
- 🔒 Secure payments (Stripe integration)
- 📊 Admin dashboard with analytics and controls
- 🚫 Therapist verification & approval process
- 💼 Psychologist profile management

---

## 🛠️ Tech Stack

**Frontend**: React.js  
**Backend**: Django (Django REST Framework)  
**Database**: PostgreSQL (hosted on Amazon RDS)  
**Web Server**: Nginx  
**Containerization**: Docker  
**Hosting**: AWS EC2  
**Payment Gateway**: Stripe 
**WebSocket**: Django Channels (for chat)
